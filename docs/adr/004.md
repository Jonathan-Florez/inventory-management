# ADR-004: SKU único a nivel global, no por usuario

## Contexto
El PDF pide SKU único pero no aclara el alcance, consulte con johao que alcance deberia tener...

## Decisión
El SKU es único globalmente, a través de todos los usuarios — igual que un
código de barras real, que identifica un producto de forma absoluta sin
importar quién lo escanea.

## Alternativas consideradas
- Único por usuario (dos usuarios distintos podrían tener el mismo SKU):
  descartado tras confirmación con johao, que me aclaró la analogía de código de barras como intención del requisito.

## Consecuencias
- La validación de duplicado en `ProductService` (_ensure_sku_available)
  consulta sin filtrar por usuario, a diferencia de todas las demás lecturas
  de producto (contraste explícito con ADR-001).

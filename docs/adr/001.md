# ADR-001: Inventario aislado por usuario


## Contexto
El modelo de datos del PDF (sección 5) incluye "user_id" como FK en Category,
Product y Movement. El nombre del proyecto ("Inventario Personal") sugiere que
cada usuario gestiona su propio inventario, no uno compartido entre todos.

## Decisión
Todas las queries de lectura, edición y borrado de categorías, productos y
movimientos filtran explícitamente por "user_id" del usuario autenticado.
Un usuario nunca puede ver ni modificar datos de otro usuario.

## Alternativas consideradas
- Inventario único compartido entre todos los usuarios: más simple de
  implementar (sin filtro de user_id en las lecturas), pero contradice el
  nombre "Inventario Personal" y el hecho de que las 3 entidades tienen FK
  a User en el modelo sugerido del PDF.

## Consecuencias
- Previene vulnerabilidades IDOR (un usuario adivinando IDs de otro usuario).
- El SKU es la única excepción: se valida como único a nivel global,
  no por usuario (ver ADR-004).
